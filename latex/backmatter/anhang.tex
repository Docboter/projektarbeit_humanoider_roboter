\chapter{SLURM-Batch-Skript (Auszug)}
\label{anh:slurm}

\Cref{lst:anh-slurm} zeigt einen vereinfachten Auszug des für KISSKI verwendeten
Batch-Skripts. Charakteristisch ist die Bindung des persistenten
VAST-Projektverzeichnisses nach \texttt{/data} sowie die ausschließliche
Konfiguration über Umgebungsvariablen. Das vollständige, gepflegte Skript liegt im
Repository (\doc{Training/kisski_submit.sh}); Bedienung siehe
\doc{docs/training/kisski-hpc.md}.

\begin{listing}[htb]
\begin{minted}{bash}
#!/usr/bin/env bash
#SBATCH --job-name=groot-finetune
#SBATCH --partition=kisski            # A100 80 GB (alt.: kisski-h100)
#SBATCH -G A100:1                     # 4x A100 fuer den Multi-GPU-Lauf
#SBATCH -c 16
#SBATCH --mem=64G
#SBATCH --time=48:00:00
#SBATCH --output=logs/slurm-%j.out

module load apptainer

apptainer exec --nv \
  --bind /mnt/vast-kisski/projects/kisski-humrob/data:/data \
  --env HF_TOKEN="${HF_TOKEN}" \
  --env WANDB_API_KEY="${WANDB_API_KEY:-}" \
  --env GLOBAL_BATCH_SIZE="${GLOBAL_BATCH_SIZE:-8}" \
  --env MAX_STEPS="${MAX_STEPS:-175000}" \
  --env NUM_GPUS="${NUM_GPUS:-1}" \
  "${SIF_IMAGE}" \
  bash /scripts/entrypoint.sh
\end{minted}
\caption{Vereinfachter Auszug aus \texttt{kisski\_submit.sh}.}
\label{lst:anh-slurm}
\end{listing}

\chapter{Trainingsdynamik: Lernrate und Gradienten-Norm}
\label{anh:trainingsdynamik}

folgenden beiden Abbildungen den Lernraten-Schedule (\cref{fig:anh-lr}) sowie die
Gradienten-Norm (\cref{fig:anh-gradnorm}) für beide Trainingsläufe. Beide Größen
belegen, dass die Optimierung in keinem der Läufe instabil wurde. Die Lernrate ist
dabei vollständig deterministisch durch die Konfiguration vorgegeben (Cosine-Decay
mit linearem Warmup); die Gradienten-Norm ist demgegenüber ein gemessenes
Diagnosesignal. Sämtliche Stützpunkte stammen aus der vollständigen W\&B-History
(Lauf~1: Run \texttt{i6n1t613}, Lauf~2: Run \texttt{ajgoskon}, Projekt
\texttt{gr00t-g1-dex3}).

\section{Open-Loop-Aktionsvergleich}
\label{anh:openloop}

\Cref{fig:anh-openloop} zeigt den Open-Loop-Test aus \cref{sec:diagnose} im Detail:
Für jede der 28~Aktionsdimensionen wird die vom Modell auf \emph{echten} Bildern
vorhergesagte Aktion der aufgezeichneten Ground-Truth gegenübergestellt. Die
Armdimensionen (0--13) folgen dem Referenzverlauf gut, während die Fingerdimensionen
(14--27) deutlich verrauscht sind. Da hier echte Bilder eingespeist werden, isoliert
der Test die reine Modellgüte vom Regelkreis und von der Simulation.

\begin{figure}[p]
  \centering

  \caption{Open-Loop-Aktionsvergleich für Checkpoint~175\,000 (Episode~0). Die

    unten gelesen, Spalten von links nach rechts (Spalte~1: linker Arm~0--6,
    Spalte~2: rechter Arm~7--13, Spalte~3: linke Hand~14--20, Spalte~4: rechte

    Referenzpunkte (rot). Die Arme~(0--13) werden gut getroffen, die

\section{Kamerakalibrierung über Alpha-Blend-Overlays}
\label{anh:overlay}

Die in \cref{sec:kalibrierung} beschriebene Kamerakalibrierung erfolgte mangels
Hardware-Metadaten iterativ: Reales Datensatz-Erstbild und simuliertes Erstbild
wurden halbtransparent überlagert und die Sim-Kamerapose so lange angepasst, bis
Tischkanten, Würfel und Handpositionen zur Deckung kamen. \Cref{fig:anh-overlay}
zeigt je Kamera das reale Bild, das Overlay und das Sim-Bild nebeneinander.
