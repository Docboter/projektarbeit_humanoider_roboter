\chapter*{Zusammenfassung}
\addcontentsline{toc}{chapter}{Zusammenfassung}

Diese Projektarbeit untersucht das Fine-Tuning des \ac{vla}-Modells NVIDIA
GR00T~N1.6 für eine Block-Stacking-Aufgabe auf dem humanoiden Roboter
Unitree~G1 mit DEX3-Hand. Das vortrainierte Modell wird per \acl{il} auf rund
300 Demonstrationen angepasst. Die Arbeit umfasst eine Container-Umgebung, die
lokal und auf dem \ac{hpc}-Cluster KISSKI der GWDG läuft, drei Trainingsläufe,
eine Simulationsumgebung in NVIDIA Isaac~Lab, die Validierung der Checkpoints
und eine Reihe von Diagnosewerkzeugen.

Alle drei Trainingsläufe konvergierten stabil. In der Simulation löste jedoch
keine Politik die Aufgabe. Der zuletzt getestete Checkpoint (Stand
14.08.2026) nähert sich den Würfeln und berührt sie, schließt die Hand aber
nicht weit genug, um einen Würfel anzuheben. Die Diagnosetests deuten darauf
hin, dass vor allem der visuelle Unterschied zwischen realen und simulierten
Bildern dafür verantwortlich ist: Auf realen Bildern kommandiert dieselbe
Politik die volle Greifbewegung, in der Simulation nur ein Fünftel bis ein
Viertel davon. Wie groß dieser Anteil ist, bleibt offen, weil später ein
Fehler in der Ansteuerung der simulierten Hand gefunden wurde. Ein Lauf mit
zurückgehaltener Testmenge zeigte zudem, dass der letzte Checkpoint nicht der
beste ist. Die Arbeit beschreibt die größten Hindernisse im Projekt, leitet
Empfehlungen für Folgeprojekte ab und skizziert Co-Training mit simulierten
Bildern sowie Reinforcement Learning als nächste Schritte.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This project report examines the fine-tuning of the NVIDIA GR00T~N1.6
\ac{vla} model for a block-stacking task on the Unitree~G1 humanoid robot
with DEX3 hand. The pre-trained model is adapted via \acl{il} on roughly 300
demonstrations. The work covers a container environment that runs locally and
on the KISSKI \ac{hpc} cluster of GWDG, three training runs, a simulation
environment in NVIDIA Isaac~Lab, checkpoint validation and a set of diagnostic
tools.

All three training runs converged stably, yet no policy solved the task in
simulation. The most recently tested checkpoint (as of 14~August~2026)
approaches and touches the cubes but does not close the hand far enough to
lift one. The diagnostic tests indicate that the visual difference between
real and simulated images is the main cause: on real images the same policy
commands the full grasping motion, in simulation only one fifth to one quarter
of it. How large this share is remains open, because an error in the control
of the simulated hand was found later. A run with a held-out test set also
showed that the last checkpoint is not the best one. The report describes the
main obstacles of the project, derives recommendations for follow-up projects
and outlines co-training with simulated images and reinforcement learning as
next steps.
